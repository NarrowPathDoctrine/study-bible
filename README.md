# Narrow Path Doctrine Study Bible

Official GitHub Pages website for the **Narrow Path Doctrine Study Bible** Android app, developed by Narrow Path Doctrine Ministries.

This is an independent repository, separate from VerseMosaic, Unbroken Word, Waymark Launcher, and Android App Testers.

## Website files

- `index.html`: Study Bible homepage.
- `privacy.html`: Study Bible Privacy Policy for Google Play.
- `support.html`: Support and contact information.
- `style.css`: Responsive navy-and-gold website styling.
- `.nojekyll`: Keeps GitHub Pages in static-file mode.

All website files are in the repository root.

## GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.

Expected website: https://narrowpathdoctrine.github.io/study-bible/

Expected privacy policy: https://narrowpathdoctrine.github.io/study-bible/privacy.html

The privacy policy should be reviewed against any material changes to the Android app's data handling, permissions, dependencies, and Google Play Data safety declarations.
